# 🎮 Hangman Word Guessing Game (Python)

## 📌 About the Project
This is a console-based Hangman Word Guessing Game developed using Python as part of my 4-week Datheon Python Internship.

The game randomly selects an English word, and the player has to guess it one letter at a time before running out of attempts.

## ✨ Features
- Random English word selection from an external text file.
- Three difficulty levels: Easy, Medium and Hard.
- Six incorrect attempts allowed.
- ASCII Hangman graphics that update with incorrect guesses.
- Prevents duplicate letter guesses.
- Displays correctly guessed letters.
- Tracks wins, losses and overall win rate.
- Option to play multiple rounds.

## 🚀 How to Run the Project

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Make sure both `hangman.py` and the English word-list file are in the same folder.
4. Open the folder in VS Code.
5. Open the terminal and execute:

```bash
python hangman.py
```

## 🎯 How to Play

1. Start the game.
2. Select a difficulty level:
   - Easy: 4–5 letters
   - Medium: 6–7 letters
   - Hard: 8 or more letters
3. Guess one letter at a time.
4. Correct guesses reveal the letters.
5. Incorrect guesses update the Hangman drawing.
6. Guess the complete word within six incorrect attempts to win!
